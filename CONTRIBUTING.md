# Contributing

This repository is primarily a bounded portfolio artifact. Small corrections,
accessibility improvements, and synthetic-demo tests are welcome after the
public release.

Contributions must:

1. use synthetic data and generalized names;
2. avoid production or employer-owned source code;
3. preserve the claim boundaries in `docs/claim-boundaries.md`;
4. pass the safety scan, unit tests, lint, and site build; and
5. avoid adding a new external dependency unless it materially improves the
   teaching artifact.
