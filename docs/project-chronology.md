# Condensed public chronology

## Foundation

The project began by defining authoritative source events, adding cross-stage
tests, documenting a reproducible local data path, and treating publication as
an observable contract rather than a file upload.

## Deterministic products

The reporting layer evolved into governed two-sheet workbooks with explicit
lineage, client-independent stored values, missing-versus-zero treatment, and
semantic plus presentation certification.

## Durable publication

Canonical output ownership, conditional same-item writes, ETag-aware updates,
and exact remote readback made output state independently verifiable.

## Bounded self-healing

Expected-output accounting, fair repair, terminal holds, source preparation,
and post-lease optional work allowed the system to recover technical gaps
without inventing missing evidence or blocking unrelated reports.

## Release safety

Immutable thin successors, output-suppressed shadows, serialized handoffs, one
active writer, and exact rollback created a repeatable release path with no
planned output mutation during validation.

## Natural verification and closure

A corrected successor naturally published a missing canonical report, settled
accepted writes through GET-only readback, advanced once after a genuine
governed source change, and produced an exact no-op on the next equivalent
cycle. Remaining owner-transfer and document-governance work was kept separate
from the completed technical reliability goal.
