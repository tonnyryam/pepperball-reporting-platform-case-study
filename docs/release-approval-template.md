# Lightweight public-release approval template

Suggested message for an authorized PepperBall representative:

> PepperBall approves Thomas Ryan publishing the reviewed portfolio materials at
> commit `[PUBLIC COMMIT]`. The approved scope includes the PepperBall name,
> generalized architecture and engineering outcomes, synthetic data, synthetic
> workbook screenshots, and independently written demonstration code. It does
> not include production source code, credentials, personal or customer data,
> operational exports, private identifiers, or live report templates.

Record the approver's name, role, date, approved commit, and any requested edits
outside the public repository.
